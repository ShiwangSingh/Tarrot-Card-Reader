# Tarot Card Reader Web App

A beautiful, interactive, and fully responsive single-page tarot reading application built with HTML5, CSS3, and Vanilla JavaScript. 

Experience a mystical tarot reading session with dynamic card draws, CSS3 flip animations, and a responsive algorithm that generates a spiritual summary based on the drawn cards.

## 🌟 Features

- **Virtual Tarot Deck**: Complete dataset of 22 Major Arcana cards with meanings, predictions, and energies.
- **Randomized Engine**: Utilizes the Fisher-Yates shuffle algorithm to ensure true randomness, along with 50% probability for upright/reversed orientations.
- **Dynamic DOM Rendering**: No hardcoded UI. Everything is injected dynamically through JS.
- **Advanced UI/UX**: Dark mystical theme, starry background generation, glassmorphism elements, CSS 3D card flips, and glowing text.
- **Reading Summary Generator**: Automatically calculates a final spiritual reading based on the combined energies of the drawn cards.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/tarot-card-reader.git
   ```
2. Navigate to the project directory:
   ```bash
   cd tarot-card-reader
   ```
3. Open `index.html` in your favorite browser. No build steps or server required!

## 🌐 GitHub Pages Deployment

This project is fully deployable to GitHub Pages:
1. Push the repository to your GitHub account.
2. Go to the repository **Settings**.
3. Navigate to the **Pages** section on the left sidebar.
4. Under **Build and deployment**, select `Deploy from a branch`.
5. Choose the `main` branch and `/root` folder, then click **Save**.
6. Your site will be live at `https://yourusername.github.io/tarot-card-reader/` within a few minutes.
